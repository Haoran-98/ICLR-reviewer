# 历史定时汇总工具

此目录保存早期每天抽样、每周整合及每月更新 README 的脚本和测试。
当前项目已使用全量数据流水线、领域规则冻结库和单篇审稿 Web；这些脚本不参与网站运行。

2026-11-12 整理仓库时停止当前服务器上本项目的旧 weekly/monthly README 发布任务，
避免将旧小样本活动写回新的项目说明。其他项目和审稿版本回填任务保持原配置。
旧 `public/` 活动快照仅保留本地；历史版本仍可通过 Git 历史查阅。

不要直接运行 `install_cron.py` 恢复旧自动发布。若需使用此工具，先检查 `manage.py`
中的抽样范围、README 标记块和只允许发布四个文件的限制，再配置独立输出目录。
