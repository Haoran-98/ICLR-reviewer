# 可移植演示部署

按已授权的四步顺序发布资产、配置路径、提供命令、验证干净环境。保留现有地图与三个主题页，完成新机器上的地图、回放和自填接口审稿。

资产使用独立 Git 版本标签发布分段压缩包，主分支固定清单与 SHA-256。沿用 GitHub 的下载能力；主分支只保存源码和发布说明。三份包分别包含网站快照、冻结规则与配对来源、完成态案例。资产构建读取原件，生成派生包，保留原始版本身份、引文和上游哈希。

规则包使用相对来源目录，完整身份索引覆盖所有提炼来源，包括未生成规则的稿件。索引沿用运行时的精确全文摘要算法，纳入冻结清单。案例只读回放，新审稿建立新任务。公开包排除模型接口、密钥、登录配置、原始请求信封与开发机路径。

路径使用环境变量与项目本地默认目录。安装器校验分段、完整包、解压安全和文件清单；账号在本机交互初始化；启动脚本沿用 Vite 与 Python 同源代理。模型连接仍由使用者在页面输入。

用无开发机目录挂载的 Debian/Python/Node 容器安装公开包。浏览器依次检查地图、五篇库内回放、MLRA 完成态案例、新上传稿件、接口传递、结果及证据。确定性兼容接口用于失败/重试回归；真实模型运行单独记录。验证记录区分工程链路与审稿科学质量。

实现前的独立只读检查确认了模块双文件校验、相对来源解析、全部 1,286 篇来源排除、Web 子进程规则路径、完整案例入口，以及本地示例稿件目录这些必要依赖。
