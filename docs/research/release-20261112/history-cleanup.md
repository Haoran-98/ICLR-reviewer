# Git 历史接口配置清理

日期：2026-11-12。

## 清理范围

- 以实际本机模型配置和历史测试文件为线索，核查模型接口地址、提供商主机名与 API Key 字面量。
- 替换历史测试及研究脚本中的实际模型地址，测试采用保留域名 `.invalid`。
- 当前网站使用用户自行填写的 Base URL、API Key、模型 ID 与协议。历史研究脚本的本地模型地址改为显式配置。
- 对历史文本、提交说明及压缩内容进行检查；原始题录和论文引文按来源保留。

## 执行与核查

使用 `git-filter-repo` 重写可达提交，保留提交顺序。重写前的备份与替换字面量保存在仓库外的私有目录，权限分别为目录 `0700`、文件 `0600`。

推送采用 `--force-with-lease`，校验重写前的远程分支版本。推送后从远程重新获取对象，复查模型地址与凭据匹配结果。

执行结果将在完成远程核查后记录于本节。

## 其他克隆的同步

已有克隆建议重新克隆，并单独迁移自己的未提交工作。核查范围为仓库分支可达历史；GitHub 缓存及其他人的独立克隆由各自持有者管理。
