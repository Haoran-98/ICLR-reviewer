# S4 主题表示试验：决策留痕

记录日期：2026-10-29。实验标识：`entity_core5_gpt6luna_medium_v1`。

## 采用的方案及依据

| 决策 | 具体处理 | 依据与可核验材料 |
|---|---|---|
| 作者标签独立保存 | 原始领域与关键词不输入提取模型，顺序及重复项原样保留。 | 用户确认；`inputs.json`、`evidence/papers/`、`requests/`。 |
| 用候选集保留科学术语 | 保存全部模型候选及类型、角色、显著性、原文片段、字符位置；不把候选直接当作确认主题。 | 用户确认；SciERC、SciREX；`PROMPT.md`、`results.json`。 |
| 结构化核心内容 | 单独保存研究问题、方法、研究对象；拼接三个字段用于第二份向量。 | 用户确认；`parsed_outputs.json`、`core_text`、字段原文证据。 |
| 根据文献改编提示词 | 参考科学实体类型、显著性和详细标注指南，形成项目自定义的八类实体及角色规则。 | SciERC（EMNLP 2018）、SciREX（ACL 2020）、GoLLIE、UniversalNER（ICLR 2024）；`LITERATURE.md` 与文献来源快照。 |
| 固定调用设置 | `gpt-6-luna`；用户的 mid 对应请求参数 medium；并发上限 3。 | 用户确认；实际 API 请求与响应均记录该模型和强度。 |
| 两份向量分开保存 | 原始摘要与三字段核心内容分别编码；固定 BGE-M3 版本，在 CPU 上生成 1024 维归一化向量。 | 用户确认的双视图方案；`embeddings/`、版本、实际输入、模型文件哈希。 |
| 保留质量局限 | 原文定位验证只证明来源可追溯；候选类型、完整性、匹配收益仍需评价。 | `QUALITY_REVIEW.md`、`AUDIT_CHECKS.json`。 |

科学实体类型、角色枚举和三字段表示是本项目的改编；上述论文提供设计依据，不是本轮结果的准确率证明。

## 本轮实际结果

样本为前轮相同的 5 篇诊断论文，覆盖 2024—2026 年：19362、3059、35035、36704、30310。

- 5 个成功 API 请求，失败尝试 0；输入 13,509、输出 12,479 token（其中思考 623）。
- 保留 207 条候选记录；207 条通过原文定位检查。
- 原始摘要和核心内容各 5 条向量，共 10 条，每条 1024 维。
- 实际执行约 139.8 秒；没有据此计算语义准确率、实体召回率或审稿人匹配提升。
