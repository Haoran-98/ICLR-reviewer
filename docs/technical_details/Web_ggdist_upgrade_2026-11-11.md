# 论文评分与审稿分歧的组合分布可视化

用户已于2026年11月11日要求按讨论方案修改网站，并另存课程 Word 报告副本。本次复用现有数据与绘图依赖，不重新采集论文或调用模型。

## 设计与统计口径

- 以论文为单位计算有效评分均值；至少两条有效评分时计算篇内样本标准差（分母为 n−1）和极差。
- 默认同时呈现均分与标准差两图，可将分歧指标切换为极差；按年份分别展示，支持同一年录用与拒稿论文的并列比较。
- 采用直方分布主体、点阵、中位数与中央50%/90%分位区间的组合。区间描述论文之间的经验差异，不表示估计置信度或录用概率。
- 不平滑离散分值，均分及标准差分布使用0.25分箱，极差使用0.5分箱。点阵对大组采用40个等概率分位点；小组展示逐篇观测。
- 各组分布主体基于组内概率密度计算，并在同一指标图内使用共同的厚度缩放。图形厚度用于比较密度形状，不表示样本总数；逐组显示样本量和排除数量。
- 空组、单论文组及缺失评分分别处理。篇内标准差和极差缺少两条评分时记为缺失；原始缺失评分不补零。篇内分歧与审稿人数有关，界面保留有效评分数与论文回查。
- 领域、概念或弦带筛选驱动组合图与高分歧论文列表；列表支持查看原始评分、论文详情与原文证据。

## 实现选择

1. 保留简单直方图成本最低，但无法同时表达论文分布、中心与离散程度，未采用。
2. 采用已有 R/ggdist 生成全样本组合图，浏览器 SVG 以相同统计口径生成筛选图，作为本次实现方案。报告明确区分实际 ggdist 输出和独立交互实现。
3. 在线后端按每次筛选调用 R 也可生成图形，但增加服务依赖与响应延迟，本次使用现有静态数据交互路径。
