## 地图、共现弦图和统计

地图直接复用 S4 已有 **BGE-M3 核心内容 1024 维向量**，校验源 NPZ SHA256 和 paper_id 行映射；PCA 50 维后生成固定 t-SNE 二维坐标（随机种子 42，perplexity 40，750 迭代，PCA 初始化、learning rate auto）。不重新请求模型或生成向量。WebGPU/shader-f16 使用 Atlas，否则使用 Canvas。

弦图使用 D3 `d3-chord` 与 `d3-shape`。两概念间的权重是**同时含两个归并概念的独立论文数量**，每篇在一对标签中只计一次；对称矩阵、对角为零。点击弦带筛选两标签交集，点击圆弧或下方标签按钮筛选单标签。圆弧长度表示与当前展示标签的共现权重之和，不等于该标签论文数。

默认隐藏 framework、dataset 等通用词，可勾选“通用词”恢复；实体类型筛选针对概念保留的来源类型属性。默认显示当前年份、投稿领域和实体类型范围中的前 16 个高频概念，可改为 24/32；选中标签额外保留。无共现的纳入标签仍在下方按钮列表显示。完整实体标签可搜索，不把前 N 个图节点当成完整分类体系。

领域/标签摘要显示录用、拒稿、直接拒稿、撤稿与未知数量。中稿率为 `录用论文数/总投稿量`；分母包含录用、拒稿、直接拒稿、撤稿和决定未知的全部投稿。图表、摘要和统计表使用同一口径，不重复展示相同比率。没有可用分母时显示缺失，不返回 0%。同稿多标签的分组数量不可相加为总论文数。

当前领域、标签或标签对的评分图按年显示原始离散评分频数，可切换全部决定、仅录用、仅拒稿；每条审稿等权，缺失不记零。该交互图为原生 SVG；保留下方整个 S4 队列的 R/ggdist 静态分布。年份原始评分量表不合并。

点击“在地图查看当前论文集合”，或点击领域/标签/弦带，可将同一论文集合送入地图。该操作清空地图原有标题和决定条件，避免交集被旧筛选意外隐藏。分析年份与地图控制分开，地图上的搜索和决定条件不反向改变录用率分母。

逐篇证据区支持标题/ID 搜索，展示 S4 研究问题、方法、研究对象与核心实体记录。可从弦带匹配论文列表直接进入证据，并在地图选中同一篇论文。

## 实现与刷新

- `web/export_s4.py`：读取封存 S4，按论文 ID 对接数据库最新已采集决定和审稿；数据库事务只读且为 repeatable read，只查询所需标量列。
- `web/field_labels.py`：原始投稿领域的中文展示名，原始名称仍随数据导出。
- `web/analysis.js`：实体主题图、录用统计、交互评分、D3 弦图与原文证据。
- `web/main.js`：地图、按需详情与分析集合联动。
- `web/validate_s4.py`、`web/smoke.mjs`：数据核对及真实浏览器交互验证。

## 弦图文字避让与领域渐变更新

弦图标签从圆弧附近的自由摆放改为左右两列：按圆弧锚点的纵坐标排序，用实际字体宽度换行，再按文字高度与 9 个 SVG 单位的最小间隔前后避让。标签通过引导线连接圆弧，点击文字仍可选择概念；SVG 高度随所需文字空间增长。窄屏提供图内横向滚动，保持至少 760 px 的图宽。页面其余部分不产生水平溢出。

地图新增默认启用的“领域过渡”层，在固定二维坐标上，对各投稿领域的论文分布作高斯平滑，按局部领域密度加权混合 RGB 色值，并使稀疏边缘渐隐。混色描述邻域论文的领域构成，不添加论文的领域归属或学科边界结论。保留每点的原始领域色；年份着色模式下隐藏该层。

实现于 `web/map-surface.js`：160×160 的固定数据坐标栅格，源范围用全队列最大轴跨度扩展 25%，细/中/宽三档的高斯 sigma 分别为 3/5/8 个栅格，核截断于 3 sigma。分别平滑论文数与 RGB 总和，等价于按各领域平滑密度混色；透明度随局部密度平滑变化。只在论文集合或过渡范围变化时重算栅格，缩放和平移时复用其像素并更新坐标变换。Canvas 与 Atlas 共享此逻辑，指针事件穿透色层。

验证命令：`node web/visual-checks.mjs`，检查双领域交叉混色、领域中心色、对称性、边缘淡出、平滑宽度、空集合及单领域过滤。浏览器 smoke 额外检查 16/24/32 个节点和领域筛选后的真实 SVG 文字边界框：标签互不重叠、全部位于 SVG 内、每个标签有对应引导线；移动端保持图内滚动。另读取真实渐变画布像素，验证开关清空、三档参数及年份模式隐藏。

## 数学边界与逐级语义地图

按用户要求，当前全景地图仅显示原始投稿领域标签，领域位置由密度估计产生。设领域 d 的论文数为 n_d，二维坐标为 z_i：

`f_d(z) = (1/n_d) × Σ_{i∈d} K_h(z − z_i)`。

每个领域使用相同高斯核宽度，分区为 `argmax_d f_d(z)`。计算标量差 `m_d(z)=f_d(z)−max_{k≠d}f_k(z)`，用 `d3-contour` 的 Marching Squares 提取零等值线；同时按未归一化总密度 T(z) 的 `1.5% × max(T)` 截断稀疏外围。内部分界是优势领域的等密度线，外围线表示当前数据支持范围。领域论文数归一化使大样本领域不会仅因规模压过小领域。采用 160×160 数据坐标栅格、3 sigma 截断高斯核，细/中/宽 sigma=3/5/8；边界宽度保持 CSS 像素不随地图放大而变粗，具有白色描边和深色主线。可独立关闭填色或边界。当前 23 个原始投稿领域均形成受支持的分区，共 66 个连通轮廓，完整参数和模式位置保存在 `boundary-validation.json`。这些线反映这批样本在固定二维投影中的领域分布。

缩放与标注分三层，Canvas 和 Atlas 使用同一阈值：

| 相对初始缩放 | 地图标签 |
|---|---|
| < 2.2× | 仅原始投稿领域，标签锚定在该领域优势区内的密度峰值 |
| 2.2×–5× | “● 原始投稿领域”标记 + S4 代表主题 |
| ≥ 5× | S4 主题 + 部分论文标题、年份、决定、均分及有效评分数；可点击卡片加载详情 |

论文点半径为 `min(12, 2.3 × max(0.5,zoom)^0.55)` CSS px，随缩放连续增长；点选范围与选中圈相应增长。滚轮、＋/－按钮和重置在两种渲染器中均提供相同的分层阅读逻辑。论文卡片使用可键盘操作的原生按钮，碰撞避让后最多显示 12 个，标题悬停可查看完整内容。

`derive_topics.py` 在既有 30 个空间邻域内按**实际投稿领域**进一步分组，至少 5 篇论文才构成一组；从该组内提取有至少 2 篇论文支持的非通用 S4 概念，并按领域内论文频次 TF-IDF 排序取 3 项，生成 336 组局部主题。每项主题保留其成员论文，`validate_topics.py` 全部核验主题与前置投稿领域标记的对应。该分层用于细分浏览，S4 科学实体标签的含义保留，不声明正式学科层级。筛选后标签仅保留仍有论文支撑的主题，位置取当前该组论文的坐标均值。

数学检查包含对称双领域的等密度分界、样本数量归一化、空数据轮廓及点半径的单调性；浏览器检查包含领域全景标签、2.2×/5×分层、S4 前置领域标记、点变大、真实论文卡片与详情一致，以及实际鼠标滚轮和重置后的像素坐标恢复。局域网入口继续为 <http://172.24.246.231:5173/>。
