# S9 在线 Rebuttal MVP

状态：`规划中，尚未实现`

## 计划流程

1. 读取论文、Review 和用户提供的补充证据。
2. 将 Reviewer concern 拆成可验证的原子问题。
3. 标记所需证据类型：正文、表格、公式、引用或新实验。
4. 只解析相关页或对象。
5. Author Twin 生成多个证据受限的回答策略。
6. Reviewer Twin 独立判断 resolved/partial/unresolved/unknown 和可能分数变化。
7. 达到问题稳定、轮数上限或缺少外部证据时终止。
8. 输出最终回复、concern ledger、残余风险和预计影响。

## 硬约束

- 不虚构结果、引用、数据或已完成实验；
- 每条回复引用论文或用户提供证据；
- 无法解决时输出补实验/补解释清单，而不是伪造答案；
- Reviewer 沉默保持 unknown；
- “可能改变分数”是条件推断，不是保证。

## Gate

- concern 状态可审计；
- 多轮过程有明确终止条件；
- 输出与 S5 可观察轨迹定义一致；
- 敏感输入沿用 S8 TTL 和清理策略。
