# S7 离线闭集评测

状态：`规划中，尚未实现`

## 评测协议

- 2024、2025、2026 每年独立 70% train、15% calibration、15% held-out test；
- test 在所有模型、标签、阈值、prompt 和 taxonomy 选择完成后才解封；
- 额外执行 2024 -> 2025、2024-2025 -> 2026 滚动时间评测。

## 计划指标

- 领域匹配和 taxonomy assignment；
- 评分校准；
- Review 相关性和关键缺点覆盖；
- Rebuttal outcome；
- 反事实合理性；
- 年度漂移、置信度和失败类型；
- 成本、延迟和可重复性。

## 对照组

- 标签/关键词检索；
- 单 Agent；
- 不使用 twin 的通用 Reviewer 组；
- 必要时包括简单年度先验。

## Gate

- 各年度 test 无泄漏；
- 性能优于简单基线；
- 置信度校准可靠；
- 人工盲评确认 Review 可操作；
- 若评分预测不可靠，在线阶段只输出 Review 与不确定性，不输出接受概率。
