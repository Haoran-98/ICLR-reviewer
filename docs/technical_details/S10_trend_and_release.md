# S10 趋势预测、发布与持续更新

状态：`规划中，尚未实现`

## 计划输入

- 按年份冻结的领域和 taxonomy；
- Review、评分、Rebuttal 和录用模式；
- S7 的年度内与滚动时间评测；
- 数据、模型、prompt 和 profile/twin 版本。

## 计划分析

- 投稿主题和方法变化；
- 审稿标准与 concern 类型变化；
- idea 时效性；
- 领域增长、收缩和跨领域连接；
- Reviewer 行为和评分校准漂移。

## 回测

- 使用 2024 train/calibration 预测 2025 test；
- 使用 2024-2025 train/calibration 预测 2026 test；
- 只有通过历史回测的信号才能进入 2027 预测；
- 无回测支持的内容只能标记为 hypothesis/scenario。

## 产物和 Gate

- 2027 多领域、多视角趋势；
- 每个预测的置信区间、支持证据、反例和失败条件；
- 数据/代码/模型/文档版本；
- 公共与私人数据边界审计。

趋势信号弱时输出情景分析，不输出单一路径或“必然趋势”。
