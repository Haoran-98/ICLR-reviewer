# 用户自填 OpenAI 兼容审稿接口

2026-11-12。单篇审稿页取消预设提供商列表，改为自行填写 Base URL、API Key、模型 ID，并选择 Chat Completions 或 Responses。论文探索与 Skill 库的可视化逻辑保持原样。

## 输入与执行

- 所有连接字段初始为空，密钥使用密码框。上传、历史回放和论文浏览无需填写模型配置。
- 提交新任务或重试时，同源 POST 携带 `connection`；服务器校验 HTTP(S) 地址、字段长度、控制字符、协议及 URL 中的账号/查询/片段。
- 新任务只接受用户输入，不回退读取服务器 `auth`、供应商环境配置或默认模型。
- 配置作为参数交给现有串行任务队列，在子进程环境中传递；命令行只包含 `--review-model custom`，不携带地址或密钥。
- 同一配置用于范围识别、规则适用性判断和最终审稿。调用路径由协议拼接，HTTP 重定向不自动跟随。

## 凭据生命周期

页面不使用 localStorage/sessionStorage 保存地址、密钥或模型；提交成功清空密钥，重新加载字段留空。当前实现不提供“记住密钥”。

队列及执行中的配置仅在进程内存存在；任务结束释放引用。任务清单、组合配置和请求身份只保存模型、协议、地址哈希及代码版本。供应商响应若回显地址或密钥，会在落盘前脱敏；错误消息不会回传连接信息。

服务停止后，中断任务状态与已完成结果保留，连接凭据不保留。重试须重新填写原地址/模型/协议，可以输入更新后的密钥；不匹配时不递增尝试次数、不复用已有阶段。旧版预设接口任务保留回放，重新审稿创建自填接口新任务。

既有研究 CLI 的旧提供商配置路径保留用于历史实验；Web 不使用该路径。历史试验原件保留本地，不发布真实接口配置。

## 验证范围

`web/test_review_api.py` 检查无凭据拒绝、无服务器配置回退、地址/密钥不进入任务文件和响应、密钥仅经子进程环境传递、重试重新输入及身份一致性。

`scripts/test_manuscript_review_models.py` 检查地址与字段验证、OpenAI 两种传输、模型别名返回、地址哈希、供应商回显脱敏及禁用 HTTP 重定向。

`web/review-smoke.mjs` 检查空白输入、密码框、连接字段提交、本地存储无凭据、刷新清空、已有案例与证据回放。默认使用虚构地址并拦截提交，不调用真实模型。实际密钥和地址不进入测试报告或网站截图。

两个旧测试文件中的实际接口地址已替换为虚构测试地址。本轮进一步清理 Git 历史中的模型接口配置，执行与远程核查见 [历史清理记录](../research/release-20261112/history-cleanup.md)。
