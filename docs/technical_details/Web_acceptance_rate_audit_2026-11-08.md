# 网站中稿率偏高的口径核查

核查日期：2026-11-08。页面数据快照：2026-11-06T09:05:09.404421+00:00；版本：`s4-433874ad15af3800`。

## 结论

主要原因是分母不同。页面“中稿率”采用 A/(A+R)，将撤稿与直接拒稿从分母排除。当前样本为 40.76%；同一批论文采用 A/全部则为 29.44%。分母切换带来约 11.33 个百分点差异（按未四舍五入的比例计算）。

本地完整数据库 38,890 篇采用相同两种口径分别为 40.35% 与 29.09%。S4 样本相对本地全量的差异分别约 +0.42 和 +0.34 个百分点，主要差异来自分母定义。对照范围为本地库。

| 指标 | S4 样本 | 本地完整库 |

将直接拒稿纳入而仍排除撤稿时为 39.30%，可见本次分母差异主要来自撤稿。各指标回答的问题不同，不能把其中一个无条件称为“官方口径”；对外比较要核对相同年份、分母与提交资格。

## 抽样与数据一致性

S4 队列由本地 38,890 篇按年份×原始主领域做约三分之一比例配额抽样，保留先前已完成的 500 篇，再随机补足；没有按录用状态平衡抽样。旧种子保留与随机波动可造成差异，因此 S4 率仍应标为样本描述。本轮用完整库对照，量化结果表明总体抽样差异较小。

当前 12,964 篇与数据库最新决定逐篇对照，状态差异为 0；S4 和本地完整库的论文 ID 重复均为 0；数据库不存在同一论文多种决定类别的记录。录用仅归并 Poster、Spotlight、Oral，拒稿、直接拒稿与撤稿分开。未发现重复计数、旧决定或错误状态归并造成整体升高的证据。

## 页面改进建议

1. 主指标可采用“录用占全部样本 A/N”，辅指标明确命名“接收／拒绝决定中的录用占比 A/(A+R)”；二者同时给出计数与分母。
2. 在领域树的简略行、悬停和无障碍标签中也使用完整口径名，避免只有下方统计区解释了公式。
3. 将撤稿、直接拒稿占比与年份并列展示；小样本主题显示 n 与 A/R/W/D 计数，并提示比例波动。
4. 与官方数字比较前，核对当年官方分母是否包含撤稿、直接拒稿、不完整提交等。本报告没有将 A/全部直接认证为官方口径。

本轮只做分析与报告，不修改网站已有计算。
