# 论文图审查能力与提取记录

核查日期：2026-11-12。**领域 Skill 库已提取论文图相关检查规则；当前网站通过正文和提取到的图注执行文本核查，实际图像审查待接入。**

## 已提取的检查规则

以下六条来自冻结库 `llm-area-v1`，均为 `source_supported`。该状态要求至少两篇独立论文的 Review 与正文配对来源；科学正确性按独立评测协议验收。每条规则保留适用条件、检查步骤、问题成立条件、消除问题的证据与历史来源。

| 规则 | 检查内容 | 适用情形 | 独立来源论文数 |
|---|---|---|---:|
| R1176 | 图例、坐标、比较对象、条件与误差量定义 | 用图比较模型损失/误差，或展示数学结构与计算量映射 | 2 |
| R0863 | 实验图的不确定性呈现 | 重复运行或抽样的随机性可能影响结果解释 | 2 |
| R5059 | 误差条/区间含义、重复次数和统计单位 | 定量结果以误差条、区间或重复试验摘要报告 | 2 |
| R2715 | 流程图的输入、关键变换、输出与正文步骤对应 | 多步骤/多模块方法，以及支撑核心主张的经验结果 | 2 |
| R0315 | 训练曲线异常、稳定性与优势归因 | 以训练曲线或汇总图支持性能、稳定性或退化解释 | 3 |
| R0145 | 低维投影、样本选择与表示能力主张的证据关系 | 用表示、聚类或潜在空间可视化支持结构或迁移主张 | 8 |

规则原文、来源论文 ID 与库文件 SHA-256 保存在 [提取核查记录](research/release-20261112/figure-capabilities.json)。表中列出本次逐条核查的六个例子。组合器按目标稿件适用性和预算选择规则。

| 层次 | 已实现内容 | 依据 |

当前 Chat Completions 与 Responses 请求发送文本。涉及曲线形状、误差条是否实际绘出、颜色/图例对应、坐标刻度、视觉可读性或图中数值的问题，需查看实际图像后核实，审稿中应归入 `needs_verification`。文本中的图注和正文能够支持的判断按现有引文定位规则执行。

解析器比较曾对 8 个困难公式/表格页进行独立视觉冲突审计，记录见 [40 篇报告](../benchmarks/parser_comparison/standard_40_report.md)。该实验结果用于解析器选型；网站的单篇审稿仍使用上表的文本执行路径。

## 后续接入条件

1. 从稿件保留页面图像，建立图号、图注、页码、裁剪框与文件哈希的对应关系。
2. 对需要图像证据的已选规则，调用用户配置且支持图像输入的模型；记录文本与图像的覆盖状态。
3. 将视觉判断绑定到页码和图像区域，在 concern 中支持点击查看。
4. 用人工标注图示缺陷与正常样例评估误报、证据定位及图文一致性。
